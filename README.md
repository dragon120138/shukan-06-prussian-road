# 【书刊6】 普鲁士道路后发国家的转轨研究

> 学术·历史

## 关于本书

后发国家如何现代化，普鲁士是最早最完整的案例。从土地改革讲到铁路网，从军队讲到官僚制，讨论农业贵族社会如何在百年内转轨为工业强权及付出的代价。核心命题：后发转轨不是单变量改革，而是土地解放、官僚制执行力、军队组织模板与铁路全国市场的同步重构，任何一环滞后整体失衡——1848年的失败与1871年的成功差异正在于此。
